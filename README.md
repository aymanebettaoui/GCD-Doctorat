# GCD-Doctorat
Optimisation et automatisation des processus d'inscription et de réinscription au cycle doctoral, dans le respect des normes pédagogiques marocaines.

## Diagrammes d'activité

### 1. Diagramme d'activité — Inscription

Ce diagramme présente le processus d'inscription au cycle doctoral sur la plateforme GCD, dans une version simplifiée et automatisée, tout en respectant les normes pédagogiques du cycle doctoral.

![Diagramme d'activité — Inscription](diagrammes/activite/GCD_inscription_simplifiee.png)

### 2. Diagramme d'activité — Réinscription

Ce diagramme présente le processus de réinscription au cycle doctoral sur la plateforme GCD, dans une version simplifiée et automatisée, en conservant les étapes réglementaires essentielles : suivi scientifique, validation, et gestion des prolongations.

![Diagramme d'activité — Réinscription](diagrammes/activite/GCD_reinscription_simplifiee.png)
